# aypan17.github.io

Personal website, served by GitHub Pages as plain HTML — no build step.

- `index.html` — all content (bio, publications, contact)
- `style.css` — styling
- `images/` — profile photo and figures
- `.nojekyll` — tells GitHub Pages to serve files as-is, skipping Jekyll

To update the site, edit `index.html` and push.
